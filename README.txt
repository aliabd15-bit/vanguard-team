# Vanguard Team PWA
نسخه اولیه فارسی، راست‌چین و موبایل‌محور.

## امکانات
- ثبت و ویرایش اعضا
- پرونده اختصاصی و چک‌لیست ۱۶ مرحله‌ای رشد
- ثبت بالاسری مستقیم
- نمایش درخت تصویری و لیست بازشونده
- وظایف و پیگیری
- داشبورد و خروجی/بازیابی JSON

## نکته مهم ذخیره‌سازی
این نسخه اولیه اطلاعات را فقط در حافظه محلی مرورگر همان گوشی ذخیره می‌کند (localStorage). همگام‌سازی ابری و ورود امن چنددستگاهی ندارد. مرتب از بخش «پشتیبان‌گیری» خروجی بگیرید. برای اطلاعات حساس اعضا، از گوشی قفل‌دار استفاده کنید.

## نصب رایگان به شکل آیکون روی اندروید
برای نصب PWA باید فایل‌ها روی یک آدرس HTTPS میزبانی شوند. ساده‌ترین مسیر رایگان:
1. یک مخزن عمومی GitHub بسازید.
2. فایل‌های این پوشه را در ریشه مخزن بارگذاری کنید.
3. در Settings > Pages، گزینه Deploy from a branch و شاخه main / root را انتخاب کنید.
4. پس از انتشار، لینک GitHub Pages را در Chrome اندروید باز کنید و از منو گزینه Install app یا Add to Home screen را بزنید.

کد اپ در فایل index.html است. GitHub Pages برای مخزن عمومی رایگان است؛ توجه کنید کد برنامه عمومی خواهد بود اما اطلاعات اعضا در نسخه حاضر داخل مرورگر ذخیره می‌شود و در مخزن آپلود نمی‌شود.
